Ce que DA-Copilot fait pour vous

Contrôle qualité

Profilage chiffré : lignes, colonnes, % de valeurs manquantes, doublons, incohérences et outliers détectés avant toute analyse.

Nettoyage tracé

Chaque transformation est documentée avec son motif. Vos sources ne sont jamais modifiées : analyse sur copies uniquement.

KPI vérifiés

Chaque indicateur a une définition, une période et un périmètre explicites — recoupés par un second calcul.

Visualisations honnêtes

Axes non trompeurs, échelles lisibles, titres explicites. Des graphiques qui éclairent la décision, pas qui la maquillent.

Modélisation prudente

Comparaison de modèles, validation croisée, métriques adaptées au déséquilibre de classes — sans survendre les résultats.

Rapports actionnables

Livrable final : insights, recommandations et preuves complètes — exportable en rapport HTML autonome.

Un workflow en 5 étapes, chaque étape vérifiable

  1. ComprendreReformulation de la question métier, KPI, période, segments et public cible.
  2. Contrôler les donnéesÉtat des lieux chiffré : qualité, manquants, doublons, incohérences.
  3. Nettoyer et préparerCorrections, standardisation, colonnes calculées — avec journal des transformations.
  4. AnalyserStatistiques, tendances, segments, corrélations, anomalies — chiffres recoupés.
  5. Visualiser et livrerGraphiques, insights, recommandations et rapport final avec preuves.

Démarrage rapide

git clone https://github.com/Miacourse/da-copilot.git
cd da-copilot
pip install pandas numpy scikit-learn matplotlib seaborn

python scripts/01_profile.py   # profilage & contrôle qualité
python scripts/02_prepare.py   # nettoyage + journal
python scripts/03_eda.py       # exploration + graphiques
python scripts/04_model.py     # comparaison de modèles
python scripts/05_dashboard.py # dashboard HTML autonome

Adaptez le chemin du CSV en tête de scripts/01_profile.py (variable CSV). Fonctionne sous Linux, macOS et Windows.

Questions fréquentes

Qu'est-ce que DA-Copilot ?

Un agent d'analyse de données open source qui transforme une question métier et vos données en réponse chiffrée, vérifiable et actionnable — y compris pour un public non technique.

Comment installer DA-Copilot ?

Clonez le dépôt, installez les dépendances Python (pandas, numpy, scikit-learn, matplotlib, seaborn) et exécutez les 5 scripts du pipeline dans l'ordre.

DA-Copilot est-il gratuit ?

Oui, sous licence MIT. Le code, la méthodologie et les rapports sont librement réutilisables et modifiables.

Quelles données DA-Copilot peut-il analyser ?

CSV, Excel, Parquet et exports SQL en lecture seule. L'agent contrôle la qualité, documente chaque transformation et n'invente jamais de chiffres.

Mes données sont-elles envoyées à l'extérieur ?

Non. Le traitement est local (Python sur votre machine). Confidentialité par défaut : aucune donnée n'est transmise à un service externe.
